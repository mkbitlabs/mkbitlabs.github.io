# MK Bit Labs · Legal Website

This **public** repository contains only static HTML pages for legal and privacy information. It does **not** contain any source code, assets, releases, or private data from the **private** Glub & Blub game repository.

## Website

- Landing page: https://mkbitlabs.github.io/
- Glub & Blub privacy policy and legal notice: https://mkbitlabs.github.io/glub-and-blub/

The game's privacy button currently points directly to the second URL, so changing the app code is not necessary.

## Enable GitHub Pages (GitHub Free, one-time)

1. Open [Settings → Pages](https://github.com/mkbitlabs/mkbitlabs.github.io/settings/pages).
2. Under **Build and deployment**, select **Source: Deploy from a branch**.
3. Set **Branch: main** and folder **/(root)**, then click **Save**.
4. Wait for the GitHub Pages deployment. The website URLs above should then work.

The original `mkbitlabs/glub-and-blub` repository **must remain private**. Never change its visibility to publish this legal website.

## Publishing changes

Edit only `glub-and-blub/index.html` in this repository and commit to `main`. GitHub Pages then rebuilds the public website from the branch. No Jekyll plugins, scripts, external fonts, analytics, or advertising code are used.

Before enabling AppLovin MAX or Game Center, review and revise this legal notice and App Store privacy disclosures to match the actual native SDKs, data processing, and consent settings.
